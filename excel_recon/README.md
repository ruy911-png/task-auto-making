# 엑셀 보고서 검산 엔진 (별도 기능)

원본(raw) 엑셀로 만든 보고서 엑셀을 기계적으로 검산하는 **실행 파일 1개**짜리 파이썬 도구.
ERP 모집단 추출 도구(`src/`)와는 독립된 별도 기능이다. 작업 기록은 이슈 #1(v19~v23), 이슈 #5(v24) 참고.

**최신판: `excel_automation_v24.py`** (v23은 비교용으로 남김)

## 하는 일

| 기능 | 내용 |
|---|---|
| 원본 ↔ 보고서 대사 (합계형) | 보고서 숫자 칸마다 행·열 제목으로 원본을 걸러 합계를 비교 (소계·합계, 월·연월·연도, 차변-대변, 단위 배수 자동) |
| 원본 ↔ 보고서 대사 (행 대조, v22~) | 원본 행을 옮겨 정리한 보고서·PDF 글자 줄 원본을 거래 단위로 맞춰 값 차이 / 원본에 없음 / 보고서에 없음 / 확인 필요 판정, 열 이름이 달라도 값으로 열 대응, 같은 행 계산식(단가 = 금액 ÷ 수량 등) 위반 검출 |
| 수식·시트 연결 검사 | 수식 자리에 값, 주변 수식과 불일치, SUM 범위에서 빠진 칸, 소계 이중 합산, 없는 시트 참조, 오류값 |
| 재계산 | 기본은 `formulas` 라이브러리, `USE_EXCEL = True`면 Windows Excel(pywin32)로 재계산해 저장값과 비교 |
| 누락 값 | 빈 칸·글자로 저장된 숫자·근거 없는 칸 표시 |

## 실행

VS Code에서 ▶ 실행(인자 없음) — 같은 폴더의 원본·보고서를 자동으로 고른다.

```
py excel_automation_v24.py 원본.xlsx 보고서.xlsx          # 원본 대사 + 수식 검사
py excel_automation_v24.py 보고서.xlsx --수식             # 수식 검사만
py excel_automation_v24.py 원본.xlsx 보고서.xlsx --채우기  # 원본 집계로 보고서 값을 채운 새 파일
```

- 필요: Python 3.8+, `openpyxl` (재계산은 `formulas`, Excel 모드는 `pywin32` + Excel)
- 입력: `.xlsx` / `.xlsm` / `.xltx` / `.xltm` (`.xls`·`.csv`는 xlsx로 다시 저장 후 실행)
- 원본 파일은 수정하지 않고 결과는 `*_원본대사_시각.xlsx`, `*_수식검증_시각.xlsx`로 새로 저장
- Excel 모드: v24는 43번째 줄 `USE_EXCEL = True` (v23은 41번째 줄)

## 판정 기준 (현재 설정, 바꿀 수 있음)

| 항목 | 기준 |
|---|---|
| 합계형 허용 오차 | 0.5 (보고서 단위, 규칙표 '허용 오차'로 변경) |
| 행 대조 금액 비교 | 1원만 달라도 값 차이(실수 계산 끝자리만 허용: 1e-7 + 값×5e-16). '669,422' 글자 = 669422 숫자, '-' = 0, '005930' = 5930, 16자리 넘는 정수 번호는 쉼표·공백 빼고 글자로 비교 |
| 같은 행 계산식 | 97% 이상 행에서 성립하는 식만 인정, 허용 오차 0.1% 또는 표시 자릿수 반 단위 |
| 행 대조 자동 전환 | 합계형이 '행 단위로 옮긴 표'·'맞는 칸 0개'로 끝나거나, 같은 이름 열 3개 이상 + 행 90% 이상 일치 (원본 5만 행 이하) |

## v24 변경 (이슈 #5)

| 영역 | 내용 |
|---|---|
| 합계형 빈 칸 | 원본에 금액이 있는데 비운 칸 = '누락'(빨강). 원본 0이면 정상. 구분 제목 줄('유동자산' 빈 줄 아래 계정)은 원본 행 포함 관계로 가려 제외, 제목 아래 계정 일부만 있으면 '누락' |
| 저장값 없는 수식 | '계산값 없음' + "엑셀에서 열어 저장 후 다시 실행" 안내 (빈 글자를 돌려주는 수식은 '누락') |
| 위쪽 소계형 | 값 있는 구분 줄(유동자산 300 / 현금 / 예금)은 소계·합계·합계 열 기대값에 이중으로 넣지 않음 (v23 거짓 불일치 수정). 아래 계정 일부만 담으면(상계 계정 동시 누락 포함) '확인 필요' |
| 같은 계정 두 번 | 같은 구간·같은 줄에 같은 원본 집계 칸이 또 나오면 '확인 필요', 기대값엔 한 번만. 같은 표 다른 구간이면 '확인 필요'만 |
| 행 대조 시트 관계 | 시트를 '층'(분할 / 같은 내용 보기 / 발췌)으로 판정 → 빠진 거래·중복 기재·발췌 알림. 1~4행 작은 분할 시트도 대조. 중복 기재는 복사본 쪽에 표시(부서·연월 값, 원본 위치 범위로 판단) |
| 대조 안 한 시트 | 표로 읽지 못한 내용 있는 시트(메모·조정)가 있으면 '전부 일치' 금지 |
| 표시 | 요약 줄에 누락·계산값 없음·확인 필요 칸 수, '재검산 불가 N칸', 한글 Windows(cp949) 출력 보호 |

### v24 남은 한계

- 계정 줄을 통째로 빼고 소계·합계도 맞춰 적은 보고서는 못 잡음 (v23 동일). 표에 없는 원본 계정 검사를 넣었다가 재무상태표형 정상 보고서 오탐이 커서 뺌
- 주요/전체처럼 같은 계정이 다른 구간에 다시 나오는 정상 양식도 '확인 필요'
- 아래쪽 소계형(계정 뒤에 대분류 값) + 합계 줄은 합계 불일치로 뜸 (v23 동일)
- 가로 배치 + 소계 일부 양식 '근거 없음' (v8부터)
- 시트 경계 거래의 중복 기재 위치는 일부 반대쪽 행에 표시될 수 있음 (판정 건수는 맞음)
