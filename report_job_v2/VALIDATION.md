# v2 검증 기록

검증 환경: Python 3.12.14 / openpyxl 3.1.5 / Linux.

## 결과

- `python -m compileall -q .`: 통과
- `python -m unittest discover -s tests -q`: **66개 모두 통과**
- 독립 시험: 계산·보호 54개, 구조 분석 7개, CLI·미지원 개체 보호·검토 요약 5개
- 가상 원본 4행에서 지역별·연월별 보고서를 생성해 상세 6칸 및 총합 430을 독립 기대값과 대조: 통과
- 같은 가상 자료로 `propose → approve → run` CLI 실행: 통과
- 다른 폴더에 단일 실행 파일만 복사한 뒤 구조 분석 실행: 통과

## 주요 확인 내용

열 이름·순서·제목 행·시트 변경, 복수 대상 시트, 차변/대변에 해당하는 명시적 계수식, 합계·건수·평균·최소·최대, 숫자/문자/날짜 필터, 앞자리 0 및 긴 식별자, 중간 공백, 1904 날짜 체계, 다음 기간 행 수 증가를 확인했습니다.

미계산 수식과 Excel 오류, 빈 금액, 반복·중복 제목, 잘못된 날짜·셀 주소·설정 키, 미승인/변조 설정, 기존 숫자 잔존, 수식 덮어쓰기, 기존 출력/원본/경로 별칭 보호를 확인했습니다. 저장 셀을 서로 바꿔 총합이 같게 만든 오류도 잡는지 확인했습니다. 대조 실패 시 결과 파일이 게시되지 않습니다.

발견해 수정한 결함: 날짜 일련번호 오버플로 예외, 범위를 단일 셀로 지정한 오류, 최대·평균의 금액순 정렬, 글자로 저장된 기존 숫자 잔존 표시. 수정 후 전체 시험을 재실행했습니다.

## 확인하지 못한 사항

- Windows 실제 화면 클릭·파일 선택·배율·폰트에 대한 GUI 실행 시험
- Microsoft Excel COM/pywin32 재계산과 매크로 포함 파일의 실제 Excel 실행
- 사용자의 실무 파일과 업무별 작성 기준의 적합성

tkinter 모듈 문법·한글 요약 함수는 확인했으나 실제 GUI를 실행해 클릭한 것으로 간주하지 않습니다. 파일 저장값 대조와 기존 수식 텍스트 보존은 전체 업무 의미·수식 계산 결과의 검증과 구분합니다.

기존 v1 코드는 수정하지 않았습니다. 이 새 버전은 분리해 검토할 수 있도록 구성했습니다.
