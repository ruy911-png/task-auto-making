# 범용 엑셀 보고서 v2

파일마다 파이썬 코드를 바꾸지 않고, 기준 보고서와 원본 데이터의 연결을 설정해 새 보고서를 생성합니다. 특정 회사·계정·파일명·시트명을 코드에 고정하지 않습니다. 원본만 보고 임의의 업무 기준을 정해 바로 생성하던 v1과 별도 버전입니다.

## PC에서 실행

1. 이 폴더를 내려받아 압축을 풉니다. Python 3.10 이상이 필요합니다.
2. 처음 한 번 `python -m pip install -r requirements.txt`를 실행합니다. 기존 환경에 openpyxl 3.1.5가 있으면 추가 설치가 필요 없습니다.
3. `실행.bat`을 더블클릭하거나 VS Code에서 `report_job_v2_single.py`를 열어 ▶를 누릅니다.
4. **기준 보고서 → 원본 데이터 → 새 결과 저장 위치**를 선택합니다.
5. **파일 구조 확인** 후 사용할 시트와 제목 행을 고릅니다.
6. **표 전체 다시 구성** 또는 **특정 셀 값 갱신** 방식을 선택하고, 값 열·필터·단위·출력 위치를 고릅니다. 구조에서 찾아낸 후보는 자동 승인되지 않습니다.
7. 한글 요약을 검토하고 **확인 후 생성**을 누릅니다. 반복 업무는 **설정 저장/열기**로 재사용합니다.

기준 보고서·원본·기존 결과 파일은 덮어쓰지 않습니다. 결과는 반드시 새 이름으로 저장합니다. 설정은 JSON으로 저장되지만 일반적인 표·셀 연결은 화면에서 선택하므로 코드를 수정할 필요가 없습니다. 여러 표·여러 시트에 한 번에 연결하는 고급 설정은 상세 규칙 화면을 사용합니다.

## 지원 범위

| 기능 | 동작 |
|---|---|
| 구조 분석 | 시트·제목 후보·표 범위·값 종류·병합·수식 저장값 분석 |
| 보고서 생성 | 기존 보고서의 지정 셀을 갱신하거나 지정 범위의 표를 재구성 |
| 집계 | 합계·건수·평균·최소·최대, 여러 금액 열의 계수식, 명시적인 단위·반올림 |
| 행/열 | 여러 그룹 열, 글자별/연월별/연도별 피벗, 원본순·이름순·금액순 |
| 필터 | 글자·숫자·날짜 타입을 지정해 비교. 중간 공백과 코드 앞자리 0 보존 |
| 새 항목 | 빈 영역 확장을 허용한 표에서는 새 그룹을 포함. 기존 내용과 충돌하면 중단 |
| 재사용 | 마지막 데이터 행을 공란으로 두면 다음 기간의 추가 행도 읽음 |
| 보호 | 입력 파일 동일 경로·링크·기존 출력 보호, 승인 후 설정 변경 감지, 임시 파일 대조 후 안전하게 게시 |

`월`도 연도를 포함한 `YYYY-MM`으로 출력합니다. 여러 해의 같은 달을 무단으로 합치지 않습니다. 날짜 필터는 원본 파일의 1900/1904 날짜 체계를 따릅니다. 평균·최소·최대의 전체 값은 표시된 소계의 합이 아니라 해당 원본 전체를 다시 계산합니다.

## 중요한 결과 표시

- **연결한 셀 검증:** 계산한 모든 결과 칸을 저장한 파일에서 다시 읽어 각각 비교합니다. 총합만 같은 것을 정상으로 보지 않습니다.
- **미연결 숫자 확인 필요:** 기준 보고서에 원래 있던 숫자·날짜 중 갱신하거나 보존 대상으로 명시하지 않은 칸이 남으면 위치를 알려줍니다. 이 값들은 새 기간 값으로 갱신된 것이 아닙니다. 의도적인 상수는 상세 설정 `preserve_numeric: [{"sheet":"시트명","cell":"A1"}]`로 지정합니다.
- **수식 재계산 필요:** 수정하지 않은 기존 수식은 보존하지만 openpyxl은 계산 엔진이 아닙니다. 기본 실행에서는 수식의 계산 결과까지 검증 완료로 표시하지 않습니다. Windows Excel과 pywin32가 있는 PC에서는 재계산 옵션을 사용할 수 있습니다. 이 경로는 Linux 시험 환경에서 실제 Excel로 확인하지 못했습니다.
- **중단:** 미확정 연결, 없는 열, 중복 제목, 필요한 값의 계산되지 않은 수식·Excel 오류·금액 빈칸·잘못된 날짜·기존 내용 충돌 등은 결과를 게시하지 않고 원인을 표시합니다. 금액 빈칸을 0으로 보는 것은 `blank_amount: "zero"`를 명시한 경우만 허용합니다.

표 교체는 **확인한 범위의 내용을 대체**합니다. 행을 삽입해 다른 표와 수식을 자동 이동시키지 않습니다. 수식이 있는 칸의 교체는 별도 허용이 필요합니다. 표 크기 확장은 빈 셀로만 가능합니다.

모든 엑셀 기능을 지원한다는 뜻은 아닙니다. 복수 원본 조인, 임의의 업무 계산 의도 자동 복원, 자연어 지시 이해는 구현하지 않았습니다. 이 버전의 원본은 선택한 한 시트의 한 표이며, 결과는 여러 시트에 연결할 수 있습니다. 피벗테이블·슬라이서·ActiveX·외부 연결·지원 불명확 확장 개체가 있는 기준 보고서는 유실을 막기 위해 중단합니다. xls·암호 파일은 지원하지 않습니다.

## CLI / 재현

```bash
python report_job_v2_single.py inspect 원본.xlsx
python report_job_v2_single.py propose --reference 기준.xlsx --raw 원본.xlsx --out 후보.json
# 후보를 확인하고 unresolved 항목을 해소한 뒤 명시적으로 승인
python report_job_v2_single.py approve --reference 기준.xlsx --raw 원본.xlsx --rules 후보.json --out 승인.json
python report_job_v2_single.py run --reference 기준.xlsx --raw 원본.xlsx --rules 승인.json --out 새보고서.xlsx
# Excel 사용 가능 PC에서만 마지막 명령에 --excel 추가
python -m unittest discover -s tests -v
python examples/make_demo.py
```

종료코드: 0 = 연결한 저장값 대조 완료, 1 = 중단, 2 = 결과는 생성했지만 미연결 숫자 또는 수식 재계산 확인 필요. 문법 검사를 통과했다는 사실만으로 실무 결과가 맞다고 판단하지 않습니다.

## 소스 구조

- `report_job_v2.py`: 계산·승인·생성·검증·CLI
- `report_analyzer.py`: 구조 분석과 미승인 연결 후보
- `report_ui.py`: tkinter 화면
- `report_job_v2_single.py`: 위 모듈을 포함한 배포용 단일 실행 파일. 수정은 분리 소스에서 하고 `build_single.py`로 재생성합니다.
- `tests/`: 실제 파일이나 개발자 PC 경로에 의존하지 않는 독립 시험
- `examples/make_demo.py`: 가상 입력 파일·명시적인 설정으로 생성 과정을 재현

기존 `report_job/report_job_v1.py`는 변경하지 않았습니다.
