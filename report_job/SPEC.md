# report_job_v1.py — 원본(SAP 등) 데이터 → 규칙표대로 집계 보고서 엑셀 생성 (계약)

## 목적
원본 데이터(한 줄 = 한 건, SAP 다운로드 등)를 넣으면 규칙표대로 집계표 엑셀을 새로 만든다. 범용(열 이름·구조가 다른 원본에도 규칙표만 바꾸면 동작). 실행 파일 1개, VS Code ▶(인자 없음)로 끝까지 실행. 원본 파일은 수정하지 않는다.
의존: Python 3.8+, openpyxl. `USE_EXCEL = True`(파일 위쪽 상수)이면 Windows Excel(pywin32)로 결과 파일을 열어 전체 재계산 후 저장(수식 저장값 채움). 기본 False.

## 공개 함수 (시험은 이것만 사용)
- `default_rules(raw_path) -> dict` : 원본을 보고 기본 규칙 추정 (가정은 `"_가정"` 키에 글 목록).
- `load_rules(path) -> dict` : 규칙표 엑셀('규칙' 시트 A열 항목 / B열 값, '행 순서' 시트 A열 목록[선택]) 읽기.
- `build_report(raw_path, rules=None, out_path=None) -> (out_path, info)` : rules=None이면 같은 폴더 `규칙표_job.xlsx`, 없으면 default_rules. out_path=None이면 `<원본이름>_보고서_<YYYYMMDD_HHMMSS>.xlsx`(원본 옆).
  info 키:
  - `"row_keys"`: 보고서 상세 행 순서대로 행 기준 값 튜플 목록 (소계·합계 행 제외)
  - `"col_keys"`: 열 기준 값 목록 (순서대로, 합계 열 제외)
  - `"values"`: {(행 튜플, 열 값): 숫자} 상세 칸 값 (단위 적용 후, 반올림 안 함; 원본 건이 없는 칸은 키 없음)
  - `"grand_total"`: 보고서 총합계(단위 적용 후), `"raw_total"`: 필터·제외 적용 후 원본 금액 합(단위 적용 후) — 둘은 같아야 함
  - `"new_items"`: '행 순서' 목록에 없어서 맨 아래 붙은 행 튜플 목록
  - `"excluded_rows"`: 필터·제외로 뺀 원본 행 수, `"bad_rows"`: 금액이 숫자가 아니어서 뺀 원본 행 [(엑셀 행 번호, 값)]
  - `"warnings"`: 글 목록, `"rules"`: 실제 적용한 규칙 dict
- CLI: `python report_job_v1.py [원본.xlsx] [--규칙 규칙표.xlsx]`. 인자 없으면 이 파일이 있는 폴더의 xlsx 중 결과·규칙표가 아닌 최신 파일을 원본으로. 마지막 줄은 `최종: 보고서 생성 — 행 N / 열 M / 합계 X (원본 합계 Y 일치|불일치) | 저장: 경로`. 실패 시 `최종: 실행 불가 — 이유`, 종료코드 1.

## 규칙 항목 (dict 키 = 규칙표 A열 글자)
| 키 | 값 예 | 뜻 |
|---|---|---|
| 원본 시트 | 비움 | 비우면 숫자가 가장 많은 시트 |
| 행 기준 | `계정명` / `법인, 계정명` | 쉼표로 여러 열 → 왼쪽부터 계층 (보고서 왼쪽 제목 열 여러 개) |
| 열 기준 | `일자:월` / `일자:연월` / `일자:연도` / `법인` / 비움 | 비우면 금액 열 하나 (열 제목 = 금액 열 이름). `열:월`은 날짜 열에서 '1월'…'12월', `:연월`은 'YYYY-MM', `:연도`는 'YYYY' |
| 금액 | `금액` / `차변-대변` / `차변+대변` | 열 이름 또는 +,- 식 |
| 집계 | `합계` / `건수` | |
| 필터 | `구분=매출; 법인<>본사; 금액>0` | `;`로 여러 조건(모두 만족). 연산자 = <> > < >= <=. 글자 비교는 앞뒤 공백 무시 |
| 제외 글자 | `합계, 소계` | 행 기준 값에 이 글자가 포함된 원본 행 제외 (원본 안 소계 줄 등) |
| 단위 | `1` / `1000` / `1000000` | 금액 ÷ 단위 |
| 소계 | `예` / `아니오` | 행 기준이 2개 이상일 때 첫 행 기준 값마다 소계 행 ('<값> 소계') |
| 합계 행 | `예` / `아니오` | 맨 아래 '합계' 행 |
| 합계 열 | `예` / `아니오` | 맨 오른쪽 '합계' 열 (열 기준이 있을 때) |
| 정렬 | `원본 순` / `가나다` / `금액 큰 순` | 행 순서 (행 순서 목록이 있으면 그것 우선, 목록 밖 새 항목은 맨 아래 + 노란색) |
| 빈 칸 | `0` / `빈칸` | 원본 건이 없는 칸 표시 |
| 합계 수식 | `예` / `아니오` | 소계·합계를 =SUM 수식으로 (아니오면 값) |

## 원본 값 해석 (v23과 같은 규칙)
'1,000' 글자 = 1000, '(1,000)'·'1,000-'·'△1,000' = -1000, ₩·원·$ 붙은 금액, '-' = 0, 날짜는 datetime·'2026-01-05'·'2026.01.05'·'2026년 1월 5일'·엑셀 일련번호. 행 기준 값은 앞뒤 공백 제거, 열 제목 줄은 위 15줄 안에서 자동으로 찾음(위에 조회조건 줄이 있어도 됨). 원본 안 합계·소계 줄은 '제외 글자'로 뺌.

## 출력 엑셀
- '보고서' 시트: 1행 제목(원본 이름·기간·단위), 그 아래 머리글 줄(행 기준 열 이름들 + 열 값들 + '합계'), 상세·소계·합계 행. 숫자 `#,##0` (단위 1이고 소수 있으면 `#,##0.00`), 머리글 진한 파랑 흰 글씨, 소계·합계 굵게, 틀 고정, 열 너비 자동. 새 항목 행은 노란색.
- '근거' 시트: 상세 칸마다 위치, 행 기준 값, 열 값, 원본 건수, 금액 합.
- '규칙' 시트: 적용한 규칙과 가정(_가정), 경고, 제외·오류 행.
- 생성된 보고서를 v23 엔진(`excel_automation_v23.py`)의 `verify(원본, 보고서)`로 검산하면 (합계 수식=아니오일 때) 불일치 0, 상세 칸 전부 일치여야 한다.
