# 보고서 생성 job (별도 기능)

원본 데이터(SAP 다운로드 등, 한 줄 = 한 건) + 규칙표 → 집계 보고서 엑셀을 새로 만드는 실행 파일 1개.
작업 기록·검증·남은 일은 이슈 #3. 계약(공개 함수·규칙 항목)은 `SPEC.md`.

## 실행
VS Code ▶ (인자 없음): 이 파일이 있는 폴더의 최신 원본 xlsx/xlsm + `규칙표_job.xlsx`
(없으면 원본을 보고 기본값으로 규칙표를 만들고 바로 생성, 가정은 결과 '규칙' 시트에 기록)

```
py report_job_v1.py 원본.xlsx
py report_job_v1.py 원본.xlsx --규칙 규칙표.xlsx
```

- 필요: Python 3.8+, openpyxl. `USE_EXCEL = True`(10번째 줄)면 Windows Excel(pywin32)로 재계산 후 저장
- 결과: `<원본이름>_보고서_<시각>.xlsx` — 보고서 / 근거(칸마다 원본 건수·금액) / 규칙(적용 규칙·가정·제외·읽지 못한 행)
- 원본 파일은 수정하지 않음. 마지막 줄 `최종: 보고서 생성 — … (원본 합계 … 일치)`

## 규칙표 ('규칙' 시트 A열 항목 / B열 값)
원본 시트, 행 기준(쉼표로 여러 단계), 열 기준(`날짜열:월`·`:연월`·`:연도`, 글자 열, 비움), 금액(열 또는 `차변-대변`),
집계(합계/건수), 필터(`구분=매출; 금액>0`), 제외 글자(`합계, 소계, *`), 단위, 소계, 합계 행, 합계 열,
정렬(원본 순/가나다/금액 큰 순), 빈 칸(0/빈칸), 합계 수식 + '행 순서' 시트(목록 순서, 목록 밖 새 항목은 맨 아래 노란색)
