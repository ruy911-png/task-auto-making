ERP 모집단 자동 추출 도구

SAP 세션에 로그인한 상태에서 사용하세요. 새 업무는 통제 등록에서 추가합니다.

기본 정보
조회 실행은 항상 F8입니다 (실사용 통제가 전부 F8이라 별도 설정 없음).
① 조회조건 · 본 화면 필드 매핑 (조건 컬럼명 → SAP 필드 id)
② 추가 조회조건 팝업 선택사항
본 화면 입력 후 팝업을 열어 조건을 추가로 넣어야 하는 통제용 (예: FB03 전표 리스트 조회 시 Multiple Selection 아이콘으로 문서유형 추가). 열기 버튼 id를 비워두면 이 단계는 건너뜁니다.
③ 레이아웃 선택 선택사항
조회 실행 후, 엑셀 다운로드 전에 특정 레이아웃을 선택해야 하는 통제용. 여는 버튼 id를 비워두면 이 단계는 건너뜁니다.
④ 다운로드 절차 (SAP 엑셀 다운로드 메뉴)
편집 규칙
검증
담당자 확인 방식은 "담당자 매칭" 탭에서 설정합니다. 표본추출 기준은 별도 설정이 필요 없습니다 (실행 시점 모집단 건수로 자동 산정).
담당자 확인 방식
① 인사데이터 매칭
실행 시 인사데이터 엑셀(사번/이름/아이디/부서 컬럼)을 업로드합니다. 사번 → 이름 → 아이디 순으로 순차 매칭됩니다.
② 별도 참조 엑셀 업로드 매칭 SAP 미접촉
인사데이터에 담당자 정보가 바로 없는 통제용. 실행 시 전표번호 등의 키로 담당자를 찾을 수 있는 매핑 엑셀을 업로드합니다.
③ SAP 보조조회 구현 예정
전표번호 등을 키로 별도 SAP 트랜잭션을 추가 조회해 담당자를 찾는 방식입니다. 아직 구현되지 않아 이 방식을 선택한 통제는 실행할 수 없습니다.
실행 설정
이 통제는 담당자 확인 방식이 "SAP 보조조회"로 설정되어 있어 아직 실행할 수 없습니다. "담당자 매칭" 탭에서 다른 방식으로 바꿔주세요.
